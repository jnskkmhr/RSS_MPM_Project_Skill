## 7. Known bugs and open issues.

- A single fixed baseline material, a set of preset comments, training randomization, and a time-varying evaluation material are four different conditions. The existing code supports all, but T4 must explicitly select one for each experiment.
- `MATERIAL_NAME='sand'` does not disable material reset events. Pure moving-patch Play currently still randomizes them; mixed/fixed-bed Play do not. Nominal tests must inspect resolved events.
